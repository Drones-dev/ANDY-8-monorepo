# Architecture

The documentation repository is the operator-facing source of truth for the implemented system.

# Setup

Start with the protocol, firmware, routing, bridge, and SITL repositories before connecting hardware.

# Operations

Use the ground station and monitoring repositories for live state. Use command center procedures for authorized actions.

# Troubleshooting

Check power and pinouts, radio initialization, PING/PONG health, route state, packet CRC/TTL, and ground-station serial input in that order.
