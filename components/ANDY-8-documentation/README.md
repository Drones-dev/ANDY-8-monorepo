# ANDY-8 Documentation

Canonical technical and operational documentation for the ANDY-8 project.

## What this repository does

It stores architecture descriptions, setup guides, operating procedures, API references, protocol notes, test plans, troubleshooting guides, release notes, and links between the project repositories.

## Integration contract

- Documents the implemented behavior of the code repositories, not assumed behavior.
- Every major interface points to its owning repository and version.
- Operational procedures distinguish simulation, bench, HIL, and flight use.

## Planned layout

`architecture/` · `setup/` · `operations/` · `api/` · `troubleshooting/` · `release-notes/`.
